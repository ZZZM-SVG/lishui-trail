# 测试样例（正常 / 边界 / 失败三类）

> 对应官网 4.2 第 6 项「测试样例」。
> 全部样例**不需要模型、不需要联网**即可复现；原始输出见
> [`docs/evidence/regression/verify_case_matrix.txt`](evidence/regression/verify_case_matrix.txt)。

```bash
node tests/case_matrix.mjs        # 15 例（正常 5 / 边界 6 / 失败 4），退出码 0 = 全部符合预期
```

样例直接调用插件的 6 个工具（`execute()`），与在真实 AGH 中由模型调用时走的是**同一套代码路径**
（真实会话证据另见 [`docs/evidence/`](evidence/)）。

## 五、为什么这些样例值得看

1. **失败也是设计过的输出**：三处失败出口都返回结构化的 `reason` + `hint`，模型可据此自动改参重试。
2. **自校验独立于求解器**：距离用 Haversine 重算、分段与坡度用地形模块重算，
   "通过"不是把求解器的结论再念一遍。
3. **可复现性每次都真跑**：AGH 工具路径下每次都同种子再解一次并比对几何哈希。
4. **真实 AGH 环境验证过**：同一套代码在真实 AGH 中由 Agnes 模型调用，
   5 步工具链首次调用全部成功（见 [`docs/evidence/`](evidence/)）。
